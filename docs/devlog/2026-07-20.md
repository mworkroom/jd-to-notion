## Phase 2.5 대학 도메인 우선 판별 및 학위 오타 정규화

### Work Summary

담당자가 작성한 대학명보다 공식 과정 URL의 도메인이 더 일관되다는 실무 패턴을 반영했다. 또한 `MSc`를 `MCs`로 잘못 입력하는 반복 오타가 major 매칭을 방해하지 않도록 정규화 규칙을 추가했다.

### Work Completed

- 대학 판별 우선순위를 URL domain → CSV alias → 원문 대학명으로 변경했다.
- 작성 대학명과 URL domain이 충돌하면 domain이 가리키는 대학을 선택하게 했다.
- URL domain이 CSV에 없으면 기존처럼 작성된 한국어·영문 alias를 사용하게 했다.
- 독립 학위 표기 `MCs`, `MCS`, `Mcs`, `mcs`를 대소문자와 관계없이 `MSc`로 정규화했다.
- 담당자 원문은 `programmeNameOriginal`에 보존하고, major 검색 키와 Notion 생성 후보에만 교정된 `MSc`를 사용했다.
- domain 충돌, alias fallback, `MCs` 위치·대소문자 변형을 검증하는 테스트를 추가했다.

### Decisions

실제 학교 공식 URL의 host는 담당자가 수기로 적은 대학명보다 오타·약칭·표기 변형의 영향을 덜 받으므로 최우선 근거로 사용한다. `MCs`는 `MRes`와 구조적으로 다르고 `MSc`의 글자 순서 오타일 가능성이 높으므로, 다른 문자열 내부가 아닌 학위 위치에서만 `MSc`로 교정한다.

### Current Status

도메인과 alias가 모두 있으면 도메인을 선택하고, 도메인을 알 수 없으면 alias로 정상 fallback한다. `MCs` 변형은 major 검색 키에서 제거되고 Notion 생성 후보에는 `MSc`로 기록된다. 전체 자동 테스트는 53 passed, 0 failed이다.

### Next Steps

- 서버를 재시작한 뒤 실제 JANDI 코멘트에서 domain 우선 판별과 `MCs` 교정 결과를 화면으로 확인한다.
- 새로 발견되는 학위 오타는 광범위하게 추정하지 말고 반복 사례가 확인된 표기만 회귀 테스트와 함께 추가한다.
