## Decisions - Google Sheets Phase G3 테스트 시트 controlled sync

- values append를 두 번 호출하지 않고, target과 history의 정확한 좌표를 계산하여 한 atomic batch에 포함한다.

전체 자동 테스트 154개가 통과했고 운영 `EDM.ahk` 전체 문법 검사도 종료 코드 0으로 통과했다. 현재 실행 중인 3000번 서버에서 ensure-running 경로를 확인한 결과 PID `18244`가 유지되고 HTTP 200을 반환하여 기존 서버를 중단하거나 교체하지 않았다. 운영 AHK는 새 프로세스 PID `8680`으로 재로딩되어 수정된 F12가 현재 활성 상태다. 다른 Codex 작업을 보호하기 위해 이번 작업에서는 실제 서버를 종료하거나 Windows를 재부팅하는 cold-start 실험은 수행하지 않았다.
