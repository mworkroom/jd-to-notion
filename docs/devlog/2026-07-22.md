## EDM.ahk v2 문자열 오류 수정

J님이 실제로 사용하는 `C:\Users\Marion\Documents\Automation\AutoHotkey\EDM.ahk`에서 PowerShell 명령 문자열의 따옴표 결합 오류가 발생했다. AutoHotkey v2의 문자열 파싱에 맞춰 `Chr(34)`와 명시적 연결 연산자로 명령을 조립하도록 수정했고, 실제 프로젝트 경로의 CDP 검사기 파일을 가리키도록 경로도 고정했다. 이제 기존 EDM webhook 기능은 건드리지 않고 JANDI 가져오기 블록만 다시 로드할 수 있다.

후속 실행에서 `.mjs` 파일 자체가 VS Code로 열리는 문제가 확인되어 PowerShell 명령에 `node` 실행기를 명시했다. 실제 동일한 명령 형태로 Node 실행과 출력 파일 생성을 확인했다.

추가로 Jandi가 일반 실행되어 9222 포트가 닫힌 경우 검사기의 `ECONNREFUSED` 오류가 앱에 붙여넣어지는 문제가 확인됐다. AutoHotkey가 Node exit code와 오류 문자열을 검사한 뒤 오류 결과를 버리고 수동 `⋯ → Copy` fallback으로 넘어가도록 수정했다.

JANDI의 실제 채팅 메시지는 `.message.article._message` 구조이며, 기존 `.message-card`는 숨겨진 도구 카드였음을 확인했다. extractor selector를 `.fn-user-name`, `.article-date`, `.article-body._messageBubbleTarget` 기준으로 교체하고, `:hover`가 잡히지 않는 환경을 위해 AutoHotkey의 화면 마우스 좌표를 CDP 검사기에 전달해 DOM 카드 좌표와 비교하도록 확장했다.

JANDI 원문이 한글 깨짐으로 붙는 문제를 해결하기 위해 PowerShell stdout 리다이렉션을 제거하고 Node가 `utf8`로 결과 파일을 직접 쓰도록 변경했다. 브라우저 앱 비활성 탭 문제는 Chrome 창 제목 기반 활성화의 한계로 확인했으며, 안정적인 사용 방식은 입학요강 앱을 별도 Chrome 앱 창으로 여는 것이다.

## Decisions

JANDI의 hover 메뉴 위치를 AutoHotkey가 직접 인식하도록 만들지 않고, J님이 `⋯ → Copy`를 직접 누르는 지점까지 허용한다. 이후 단계는 클립보드 변경 감지로 연결하면 화면 배율·창 위치 변화에 덜 민감하고 구현도 단순하기 때문이다. 브라우저 앱은 붙여넣기 이벤트와 기존 분석기를 유지하고, 향후 Tauri에서는 클립보드 접근 어댑터만 교체할 수 있도록 했다.

## Current Status

코드와 AutoHotkey 예시는 추가했다. 기존 자동 테스트 62개는 모두 통과했고, 로컬 브라우저에서 단축키로 입력 포커스·기존 내용 선택을 확인했으며, 붙여넣기 후 자동 Analyze와 검토 화면 표시까지 확인했다. 자동화 실행 전제는 AutoHotkey v2, 앱 창 제목 `Admissions Guideline Helper`, 매크로 키의 `F13` 매핑이다. 실제 JANDI 창에서의 end-to-end 확인은 J님의 로컬 환경에서 남아 있다.
