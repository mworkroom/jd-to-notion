# 2026-09-02 JD to Notion Development Log

## Work Summary

생성된 Word 문서에서 전공명을 더 쉽게 구분하고, 담당자 원문 URL을 별도 편집 없이 바로 열 수 있도록 전공명 굵기와 URL 하이퍼링크를 자동 적용했다.

## Work Completed

- `[[PROGRAMME]]` 마커를 검토된 Notion용 Major 이름으로 치환하면서 해당 Word run에 굵기 속성을 추가했다.
- `[[URL]]` 마커를 보이는 원문 URL은 그대로 유지한 외부 하이퍼링크로 치환했다.
- 전공별 URL에 고유 relationship ID를 발급하고 `word/_rels/document.xml.rels`에 외부 링크 관계를 추가했다.
- 템플릿의 기존 run 속성, 문단, 표, 머리말과 다른 패키지 부품은 그대로 보존하도록 기존 블록 복제 방식을 유지했다.
- 테스트 fixture와 Word 생성 회귀 테스트에 굵기, 링크 요소, 외부 관계, XML 특수문자 URL 검증을 추가했다.
- Phase 5 문서 생성 명세를 실제 동작에 맞게 갱신했다.

## Decisions

- 템플릿 파일을 직접 수정하면 SHA-256을 다시 등록해야 하므로, 서식과 링크는 생성 코드에서 적용하기로 했다.
- URL 문자열을 바꾸거나 Word의 자동 링크 감지에 의존하지 않고, 표준 OOXML 하이퍼링크 요소와 외부 관계를 함께 생성하기로 했다.
- 기존 문서 서식을 침범하지 않도록 전공명과 URL 마커가 포함된 run만 국소적으로 수정한다.

## Current Status

- Node 전체 자동 테스트 176개가 통과했다.
- 실제 등록 템플릿을 읽어 전공 3개짜리 QA DOCX를 생성했고, 세 전공명 run의 굵기와 세 URL의 `w:hyperlink` 및 외부 관계 연결을 구조적으로 확인했다.
- 원본 템플릿은 수정하지 않았으므로 등록된 SHA-256을 갱신할 필요가 없다.
- 이 PC에 LibreOffice가 설치되어 있지 않아 문서 지침의 PNG 렌더링 시각 검증은 수행하지 못했다. XML 구조와 관계 유효성은 별도로 검증했으며 Microsoft Word에서 실제 링크 클릭은 아직 확인하지 않았다.
