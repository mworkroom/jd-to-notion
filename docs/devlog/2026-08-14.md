# 2026-08-14 Admission Guidelines Automation Development Log

## Work Summary

JANDI 게시물을 가리킨 뒤 매크로 키를 눌렀을 때 간헐적으로 인접 게시물이 복사되는 문제를 수정했다. Windows 125% 배율에서 AutoHotkey와 Electron DOM 사이의 좌표 기준이 어긋나는 것이 원인이었으며, 배율에 의존하지 않는 hover 기반 선택으로 정리했다.

## Work Completed

- AutoHotkey에서 마우스 좌표를 읽어 CDP 추출기에 전달하던 처리를 제거했다.
- CDP 추출기가 현재 실제로 마우스가 올라가 있는 JANDI 게시물만 선택하도록 변경했다.
- hover 게시물을 확인할 수 없으면 다른 게시물을 좌표로 추측하지 않고 기존 수동 복사 절차로 넘어가도록 유지했다.
- JavaScript 구문 검사와 전체 테스트를 수행했다.

## Decisions

- DPI별 좌표 보정값을 추가하는 대신 DOM의 `:hover` 상태를 기준으로 선택한다. 이 방식은 JANDI 게시물을 클릭한 뒤 커서를 그대로 둔 상태에서 매크로 키를 누르는 실제 사용 흐름과 일치하며 Windows 화면 배율과 창 위치의 영향을 받지 않는다.
- hover 확인 실패 시 인접 게시물을 잘못 자동 선택하는 것보다 기존 `… → Copy` fallback을 제공하는 편이 안전하다고 판단했다.

## Current Status

인접 게시물을 잘못 선택하던 좌표 판정은 제거되었다. 자동 추출은 마우스가 대상 게시물 위에 있을 때 동작하며, 그렇지 않으면 수동 복사 안내로 전환된다.

## Next Steps

- 실제 JANDI 창에서 서로 높이가 다른 인접 게시물을 대상으로 매크로 키 동작을 확인한다.
- hover 상태가 유지되지 않는 특수 상황이 확인되면 클릭한 게시물 ID를 별도로 저장하는 방식을 검토한다.
