# 2026-09-16 JD to Notion Development Log

## Work Summary - SOP 차수 충돌과 자동 다운로드 분리

요청글과 첨부파일명에 서로 다른 SOP 감수 회차가 적힌 경우 차수 검토는 계속 요구하되, 학생명과 대상 첨부파일이 확정되면 파일 자동 다운로드는 독립적으로 진행하도록 변경했다.

## Work Completed - SOP 차수 충돌과 자동 다운로드 분리

- SOP 자동 다운로드 시작 조건에서 추출 API 전체 성공 여부를 제거했다.
- 요청 유형이 SOP이고 학생 이름이 확인되면 차수 오류가 있어도 다운로드 패널을 arm하도록 변경했다.
- 학생 이름이 없거나 SOP 요청이 아닌 경우에는 기존처럼 다운로드 감시를 시작하지 않거나 취소한다.
- 송모민 요청 사례를 재현해 본문 1차와 첨부파일명 2차가 충돌해도 다운로드 요청이 전송되는 Chrome 회귀 테스트를 추가했다.
- 같은 사례에서 학생명은 유지되고 감수 회차만 미확정 상태가 되는 서버 회귀 테스트를 추가했다.

## Decisions - SOP 차수 충돌과 자동 다운로드 분리

- 감수 회차는 Notion 작업 일지의 제목과 이전 차수 Major 선택에 영향을 주므로 확정 전까지 Notion 조회·생성을 계속 차단한다.
- 파일 다운로드와 학생명 기반 파일명 정리는 감수 회차를 사용하지 않으므로 회차 충돌의 영향을 받지 않게 한다.
- 다운로드 안전 조건인 학생명 확인, 단일 SOP 첨부파일 선택, 다른 Student 이름 충돌 검사는 기존 서비스에서 그대로 적용한다.

## Current Status - SOP 차수 충돌과 자동 다운로드 분리

- Node 전체 테스트 194개가 통과했다.
- 데스크톱 Chrome Playwright 11개 시나리오가 통과했다.
- 새 회귀 시나리오에서 차수 오류 안내 유지, 자동 다운로드 arm 실행, Notion 항목 확인 버튼 비활성화를 확인했다.
- Node와 Playwright를 동시에 처음 실행했을 때 테스트용 서버 기동이 15초를 넘어 Playwright가 시작 전에 종료됐지만, Playwright를 단독 재실행하자 정상 기동되어 전 시나리오가 통과했다.
- 실제 JANDI 첨부파일은 불필요한 다운로드를 피하기 위해 자동 클릭하지 않았다.
