## Work Completed

- 작성된 대학과 URL domain이 서로 다른 프로그램을 `university_domain_conflict`로 보고하게 했다.
- 학과명과 연결되지 않은 URL을 `orphan_url`, URL 없이 남은 학과명을 `missing_programme_url`로 보고하게 했다.
- 추출 경고 전체를 Programmes 상단에 요약하고 오류·주의 색상과 문구를 함께 표시했다.
- 각 프로그램 카드에 대학·학과 요약과 `정상`, `검토 필요`, `확인 필요` 상태를 추가했다.

- alias 매칭, 원문 대학명, major search key, Notion major 후보를 `매칭 상세 보기` 안으로 접었다.
- 긴 URL 대신 domain을 기본 표시하고 `전체 주소 보기·수정`에서 원문을 편집하게 했다.
- 실제 Sussex/SOAS 코멘트를 회귀 테스트로 추가하고 전체 54개 테스트를 통과했다.
- 로컬 브라우저에서 경고 3개, 상태 강조, 상세 접기, URL 편집, 브라우저 오류 없음을 확인했다.

## Decisions

입력 순서가 틀렸을 때 파서가 임의로 프로그램과 URL을 재배치하지 않는다. 여러 의도로 해석될 수 있는 입력이므로 충돌·누락을 명확히 보여주고 J님이 원문을 수정하도록 한다. 색상만으로 상태를 전달하지 않고 상태 문구와 구체적인 설명을 함께 제공한다. Notion Preview 이후 영역은 Phase 3에서 별도로 재정비하기로 했다.

## Current Status

제공된 문제 코멘트를 붙여 넣으면 프로그램 2개와 추출 경고 3개가 표시된다. 정상 Sussex 카드와 충돌 SOAS 카드가 시각적으로 구분되며, 매칭 상세와 전체 URL은 기본적으로 접혀 있다. 자동 테스트는 54 passed, 0 failed이고 브라우저 콘솔 오류는 없다.
